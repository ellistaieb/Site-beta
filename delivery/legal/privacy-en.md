## 2. Browsing and hosting

The website uses GitHub Pages. The examined application code has no user accounts, statistics, advertising or behavioural analytics. Images, scripts and styles are served with the website; it embeds no external videos or remotely hosted fonts.

The consulted official GitHub Pages documentation states that visitors’ IP addresses are logged and stored for security purposes, whether or not they are signed into GitHub. Other technical data, retention, roles and exact uses must be specified from applicable documentation and contracts. Code inspection does not replace a full review of hosting processing.

## 3. Form, booking and entered information

The form is disabled in this version: its submission address is empty. The code therefore does not transmit contact fields to Formspree. Entered details may remain temporarily visible in the browser; the application does not program local storage of these fields.

No booking link, online payment or client account is configured. Formspree is a planned integration, not an active collection service in this version. Enabling it requires updating this policy and the form notice.
