## 2. Navigation et hébergement

Le site est hébergé avec GitHub Pages. Le code applicatif examiné ne comporte ni compte utilisateur, ni statistiques, ni publicité, ni outil d’analyse comportementale. Les images, scripts et styles sont servis avec le site ; il n’intègre ni vidéo externe ni police distante.

La documentation officielle de GitHub Pages consultée indique que l’adresse IP des visiteurs est enregistrée et conservée à des fins de sécurité, qu’ils soient connectés à GitHub ou non. Les autres données techniques, la durée, les rôles et les usages exacts doivent être précisés à partir des documents et contrats applicables. L’audit du code ne remplace pas le contrôle complet des traitements d’hébergement.

## 3. Formulaire, réservation et données saisies

Le formulaire de cette version est désactivé : son adresse d’envoi est vide. Le code ne transmet donc pas les champs de contact à Formspree. Une saisie peut rester temporairement visible dans le navigateur ; aucun stockage local applicatif de ces champs n’est programmé.

Aucun lien de réservation, paiement en ligne ou compte client n’est configuré. Formspree est une intégration prévue, pas un service de collecte actif dans cette version. Son activation nécessite une mise à jour de cette politique et de la notice du formulaire.

## 8. Vos droits

Selon le traitement et sa base, vous pouvez demander l’accès, la rectification, l’effacement, la limitation, la portabilité lorsque ses conditions sont réunies et vous opposer à certains traitements. Un éventuel consentement peut être retiré sans remettre en cause la licéité des opérations antérieures. Tous ces droits ne s’appliquent pas de la même manière à tous les traitements.

Une vérification d’identité n’est demandée que si elle est nécessaire et proportionnée. Vous pouvez adresser une réclamation à la CNIL : https://www.cnil.fr/.

## 9. Cookies et stockage sur votre appareil

Le code examiné ne lit ni ne dépose de cookie de suivi et n’utilise ni localStorage ni sessionStorage. Aucun bandeau de consentement décoratif n’est ajouté : il n’y a pas de traceur applicatif non nécessaire activé à gérer dans cette version.

Cette conclusion concerne le code du site, pas un contrôle complet des en-têtes du prestataire distant. ## 10. Évolution et prudence dans les échanges

Cette politique doit être révisée avant l’activation d’un formulaire, d’un outil de statistiques, d’une réservation, d’une vidéo externe ou de ressources distantes. Évitez d’envoyer des informations médicales ou sensibles dans une demande de contact. Les informations relatives à un accompagnement effectif doivent être encadrées séparément selon ses modalités réelles.
